# PassMath

Which ski/snowboard season pass pays off for you: Epic, Ikon, Mountain Collective and combos, priced against your own days and trips.

- `index.html` is the site Netlify serves (no build step).
- `app.html` is the same page without the HTML wrapper, used for Claude previews.

Before launch: set `EMAIL_ENDPOINT` in the script and add an analytics snippet in `<head>`.
